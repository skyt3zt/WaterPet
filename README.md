# 喝水桌宠 (WaterPet) - 安卓屏幕边缘悬浮喝水助手

一款专为提醒喝水设计的安卓屏幕边缘桌宠应用。平时以可爱水滴小形象吸附在手机边缘，每隔 30 分钟播放动效并弹出气泡提醒，支持一键打卡与稍后提醒。

---

## ✨ 核心特性

- **边缘可爱桌宠**：屏幕边缘常驻小卡通形象，手指可随意拖拽，松手后自动平滑吸附到最近的屏幕边缘。
- **定时弹出气泡**：默认每 30 分钟（可选 45m / 60m）弹出喝水提示卡片，伴随轻微震动反馈。
- **简单互动打卡**：
  - 点击「喝了一杯 🥛」：今日喝水计数 +1，小宠物跳动开心动效并自动收起。
  - 点击「稍后 (5m) ⏰」：推迟 5 分钟后再次提醒。
- **专为国产手机优化**：采用前台服务与 `AlarmManager.setExactAndAllowWhileIdle()` 精确唤醒，并提供一键加入电池白名单指引。
- **超轻量**：纯原生 Kotlin 编写，纯矢量图形绘制，无需加载庞大第三方库。

## 🛠️ 如何生成 APK 安装包

### 方式 1：使用 Android Studio 直接打包（最推荐）
1. 用 **Android Studio** 打开 `WaterPet` 目录。
2. 等待 Gradle 同步完成后，点击顶部菜单栏：
   `Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`。
3. 构建完成后，点击右下角 `locate` 即可找到 `app-debug.apk`。
4. 将该 `.apk` 文件通过微信、QQ 或网盘直接发送给朋友安装。

### 方式 2：使用 GitHub Actions 云端免费打包（无需本地安装开发环境）
1. 将当前项目上传到你的 GitHub 仓库（公开或私有均可）。
2. 项目已内置 `.github/workflows/build-apk.yml`。
3. 只要推送代码，GitHub Actions 会自动在 2 分钟内编译完成。
4. 在仓库的 **Actions** 标签页中，点击最近一次运行的构建结果，直接下载 `WaterPet-Debug-APK` 解压即可得到安装包。

## 📱 给别人安装时的操作指引（非常重要）

为了保证在不同安卓手机（小米 MIUI/HyperOS、华为 HarmonyOS、OPPO ColorOS、vivo OriginOS）上能准时提醒，请提醒对方做好以下 2 个设置：

1. **首次打开应用时**：
   - 点击界面中的「去授权」，允许应用开启 **“悬浮窗显示”** 权限。
   - 点击「电池白名单」，选择 **“允许忽略电池优化”（无限制）**。
2. **开启系统“自启动”白名单（各品牌操作）**：
   - **小米/红米**：长按桌宠应用图标 -> 应用信息 -> 开启「自启动」-> 省电策略改为「无限制」。
   - **华为/荣耀**：设置 -> 应用和服务 -> 应用启动管理 -> 关闭自动管理，勾选「允许自启动」与「允许后台活动」。
   - **OPPO/vivo**：设置 -> 电池/后台耗电管理 -> 允许后台高耗电行为。
